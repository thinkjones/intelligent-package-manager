# Catalog search — stage 2 design

Status: draft for review · 2026-10-09

## Intent

Search the artifact catalog (stage 1, `catalog/*.jsonl`) from the CLI with ranked, typo-tolerant hybrid search, and see how artifacts relate, so the data's quality can be judged before any UI is built. Stage 3 (packs, plugin generation, TUI) builds on this.

Decisions already made: Typesense, running locally in Docker; its built-in embedding model `ts/all-MiniLM-L12-v2` (no Ollama); the index is disposable and rebuilt from the committed catalog; relationships are shown as a terminal tree and as Mermaid or Graphviz exports.

### Success criteria

- `aihs serve && aihs load` brings up a populated index from a fresh clone with Docker running.
- `aihs search "c# testing" --type skill` returns relevant skills in under a second, including at least one semantic match that does not contain the query's words.
- `aihs show <id>`, `aihs tree <id>` and `aihs graph <id>` display any catalog artifact and its relationships without Typesense running.
- `mise run cli:test` needs neither Docker nor network.

## Runtime: `aihs serve`

Starts Typesense in Docker; `--stop` stops it.

- Container `aihs-typesense`, image `typesense/typesense:30.2` (pinned), port `8108` on `127.0.0.1` only, data in `<root>/.aihs/typesense/data` (gitignored with `.aihs/`).
- API key: 32 random hex characters generated on first start into `<root>/.aihs/typesense/api-key` (mode 0600), reused afterwards. The container runs `--data-dir /data --api-key <key>`.
- Idempotent: a running container is left alone; a stopped one is started; a missing one is created. Then it polls `GET /health` (every 500 ms, up to 60 s) until `{"ok":true}`.
- `--stop` runs `docker stop aihs-typesense`; data is kept.
- Docker is run through `System.Output` (`docker inspect`, `docker start`, `docker run -d …`, `docker stop`). Docker missing or not running is an error saying so.
- `aihs doctor` gains two rows: `docker` (warning if unavailable) and `typesense` (warning if not running or the collection is empty).

## Loading: `aihs load`

Rebuilds the `artifacts` collection from `catalog/*.jsonl` and `catalog/github.jsonl`: drop the collection if present, create it, import every record as one document in batches of 500 via `POST /collections/artifacts/documents/import?action=create` (JSONL). Prints the count imported per type, failures (with the record ID and Typesense's message), and the elapsed time. Exits 1 if any document failed or the server is unreachable (message: run `aihs serve`). The first load embeds every document; expect one to two minutes on CPU.

### Collection schema

| Field | Type | Options | From |
| --- | --- | --- | --- |
| `id` | string | | catalog `id` |
| `type` | string | facet | record `type` |
| `name` | string | | record `name`; for repos, the repo |
| `description` | string | | record `description`; for repos, `github.jsonl` `description` |
| `tags` | string[] | facet | record `tags`; for repos, `github.jsonl` `topics` |
| `repo` | string | facet | record `repo` |
| `plugin_names` | string[] | | names of the plugins in the record's `plugins` |
| `stars` | int32 | sort | `github.jsonl` stars of the record's repo — for an external plugin, of its `source_repo`; 0 when unknown |
| `plugins` | string[] | index: false | record `plugins` |
| `source_repo` | string | optional, index: false | external plugins |
| `path`, `commit` | string | optional, index: false | record |
| `embedding` | float[] | `embed.from: ["name","description","tags"]`, `model_config.model_name: "ts/all-MiniLM-L12-v2"` | generated by Typesense at import |

`default_sorting_field` is `stars`. `symbols_to_index: ["#", "+"]` keeps `c#`, `f#` and `c++` whole (without it, "c#" matched every "C"). Stars are joined by normalizing both sides with `pack.NormalizeRepo`.

## Searching: `aihs search <query>`

| Flag | Meaning |
| --- | --- |
| `--type T` (repeatable) | `filter_by: type:=[…]` |
| `--repo R` (repeatable) | `filter_by: repo:=[…]` |
| `--tag X` (repeatable) | `filter_by: tags:=[…]` |
| `--keyword` | keyword ranking only: `embedding` left out of `query_by` |
| `--limit N` | `per_page`, default 20, max 250 |
| `--json` | print Typesense's hits as JSON lines (one document per line, with its text-match and vector-distance info), for scripting and stage 3 |

Hybrid by default: `query_by: name,description,tags,plugin_names,embedding`, `query_by_weights: 4,2,2,1,0` (name 4, description 2, tags 2, plugin_names 1; Typesense 30.2 requires one weight per `query_by` field, so the embedding field takes a `0` — confirmed against a live server; `--keyword` uses `4,2,2,1`), `sort_by: _text_match:desc,stars:desc`, `facet_by: type`, `exclude_fields: embedding`, `num_typos: 2`, Typesense's default rank-fusion weight (`alpha` 0.3 for vectors). The query is passed as is; `*` lists everything (with filters).

Output: a table `TYPE  NAME  REPO  ★  PLUGINS  DESCRIPTION`, best first. Stars abbreviated (`31.2k`); plugins as owning plugin names joined with `, `, `—` when none; description cut to fit 120 columns total. Under it: `<found> match(es) · <type> <n> · … · <ms> ms`. Zero hits prints `no matches` and exits 0. Typesense unreachable, or the collection missing, is an error naming `aihs serve` or `aihs load`.

## Relationships

All read only `catalog/` — no Typesense.

### Graph model

Edges, built once from the catalog (`internal/catgraph`):

| From | To | Via |
| --- | --- | --- |
| repo | marketplace, plugin, copilot-plugin, skill, agent, command, hook, mcp | `repo` field (artifacts whose `repo` is that repo) |
| marketplace | plugin | `plugins` |
| plugin, copilot-plugin | skill, agent, command, hook, mcp | `skills`, `agents`, `commands`, `hooks`, `mcp` |
| external plugin | repo | `source_repo` (an unfollowed or followed `repo:` record) |

"Down" follows edges; "up" follows them reversed. A repo's direct children are its marketplaces, plus any plugin no marketplace in that repo lists, plus any component no plugin owns — so the tree from a repo shows everything exactly once.

### `aihs show <id>`

Prints the record's fields (`name`, `type`, `description`, `repo`, `commit`, `path`, `tags`, `errors` if any), the repo's GitHub stats (stars, forks, license, last push, topics) when known, then one level up and one level down as two short lists. For an external plugin it ends with `promote: aihs promote <id>`. `--json` prints the record verbatim. An unknown ID is an error suggesting `aihs search`.

### `aihs tree <id>`

A box-drawing tree (`├─ └─ │`), each line `type  name` (plus `★` for repos). `--up` walks reversed edges (a skill → its plugins → their marketplaces → repo). `--depth N` limits levels (default: unlimited down from a plugin or marketplace, 3 from a repo). More than 25 children under one node are cut to 25 plus `… <n> more`; `--all` lifts that. A node already printed on the current path is shown once with `(cycle)` and not expanded.

### `aihs graph <id>`

Exports the same neighbourhood as a diagram: `--format mermaid` (default; a `flowchart LR`) or `--format dot` (Graphviz `digraph`). Same `--up` and `--depth` (default 2) flags. Node IDs are sanitized (`n0`, `n1`, … with the catalog ID in the label); labels are `type: name`. Output goes to stdout, so `aihs graph <id> > g.mmd` or `| dot -Tsvg`.

## Code layout

| Path | Responsibility |
| --- | --- |
| `cli/internal/typesense/` | a small client over `net/http`: health, delete/create collection, import JSONL, search; base URL and key injected |
| `cli/internal/search/` | catalog records → documents (stars join, plugin names); schema; flags → search parameters; result table |
| `cli/internal/catgraph/` | load the catalog into nodes and edges; tree and graph rendering |
| `cli/internal/cli/serve.go`, `load.go`, `search.go`, `show.go`, `tree.go`, `graph.go` | commands |

No new dependency. The Typesense URL is `http://127.0.0.1:8108`; `System` gains an `HTTP *http.Client`-shaped hook so tests point the client at an `httptest` server.

## Testing

All in `mise run cli:test`, no Docker or network:

- `serve`: the fake `System` records `docker` calls — a missing container gets `docker run` with the pinned image, port bound to 127.0.0.1, the data volume and the stored key; a running one gets no call; `--stop`; Docker unavailable. Health polling against `httptest`.
- `load`: against an `httptest` Typesense — the schema (embedding field, model, facets), JSONL batches, stars joined (including an external plugin taking its source repo's stars), repos taking GitHub description and topics, failures reported and exit 1.
- `search`: parameters per flag (`--keyword` drops `embedding`, filters combine, limit capped), table rendering (stars abbreviation, `—`, truncation), zero hits, unreachable server and missing collection messages.
- `show`, `tree`, `graph`: fixture catalogs — up and down, depth, the 25-child cut, cycle marking, an external plugin's `promote` line, Mermaid and DOT output exactly.

Live verification (in the plan, run once by hand, not in the gate): `aihs serve && aihs load` over the real catalog, then hybrid and `--keyword` results compared for: "c# testing", "brand guidelines", "postgres", "code review agent", "pre-commit hook", "draw diagrams" — recorded in the plan's verification step.
