# AGENTS.md

Router for agents working in ai-harness-skills: a curated Claude Code plugin marketplace built from upstream repos by the local `ipm` CLI. Read the linked file for detail; this page is only where things are.

`ipm` was called `aihs`. Data paths still use the old name (`.aihs/`, `aihs.lock`, the `aihs-typesense` container) until part 2 of [the ipm design](docs/superpowers/specs/2026-10-09-ipm-design.md) relocates them.

## Where things are

| Path | What it is |
| --- | --- |
| `<pack>/manifest.toml` | One pack: the upstream plugins and Copilot plugins it publishes. 26 packs at the repo root; a pack folder holds nothing else. |
| `manifest.toml` (root) | Repos of interest: upstreams `ipm sync` pins, `ipm index` catalogs and `ipm scan` reports on. `ipm promote` adds to it. Publishes nothing. |
| `catalog/*.jsonl` | Generated by `ipm index` (and `github.jsonl` by `ipm stats`): every repo, marketplace, plugin, skill, agent, command, hook and MCP server in the repos of interest, deterministic and committed. Never edit by hand. See [the catalog spec](docs/superpowers/specs/2026-10-08-artifact-catalog-design.md). |
| `.aihs/typesense/` | Gitignored: the local search server's data and API key (`ipm serve`). The index is disposable; `ipm load` rebuilds it from `catalog/`. |
| `aihs.lock` | Generated by `ipm sync`: every upstream pinned to a commit. Never edit by hand. |
| `.claude-plugin/marketplace.json` | Generated by `ipm create-plugin`. Never edit by hand. |
| `.aihs/cache/<owner>/<repo>/<commit>/` | Gitignored shallow checkouts of every upstream at its locked commit. |
| [`cli/`](cli/README.md) | `ipm`, the Go CLI. `bin/ipm` is the shim `direnv allow` puts on PATH. |
| [`docs/`](docs/) | [User guide](docs/user-guide.md), [manifest reference](docs/manifest-reference.md), [architecture](docs/architecture.md). |
| [`assets/readme/`](assets/readme/) | SVGs used by the README. |

## Conventions

- **Reference, don't copy.** A pack holds only its `manifest.toml`; upstream content is fetched by Claude Code at install time, never copied or rewritten into this repo.
- **Generated files are regenerated, not edited.** Change a manifest, then run `ipm sync` and `ipm create-plugin`. Commit the manifest, `aihs.lock` and `.claude-plugin/marketplace.json` together.
- **`ipm` is local-only.** It never installs anything or writes outside the checkout. It is separate from fsh and Gas City and shares no configuration with them.
- **All CLI commands are Go**, in `cli/internal/cli`. There are no script commands.
- **Prose in Markdown is not hard-wrapped**: one line per paragraph or list item.

[`CLAUDE.md`](CLAUDE.md) has the commands and the sharp edges.
